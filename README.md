# AI-native Meetup Moscow

Статический лендинг митапа 7 ноября 2026 года.

## Локальный запуск

```powershell
python -m http.server 4173
```

Откройте `http://localhost:4173/`. Сборка и установка зависимостей не нужны.

## Подключение Timepad

После создания события скопируйте его полную ссылку вида
`https://organization.timepad.ru/event/1234567/` в константу `TIMEPAD_EVENT_URL`
в начале `script.js`. Все кнопки регистрации автоматически подключатся к одному
официальному popup-виджету Timepad.

Пока ссылка не указана, кнопки показывают сообщение «Регистрация скоро откроется».

## Публикация

Разместите содержимое каталога на любом статическом хостинге. Для шрифтов,
Яндекс Карты и регистрации Timepad посетителю потребуется доступ в интернет.
